About

I'm a senior iOS engineer moving into AI engineering. I enjoy owning a product from architecture to release: system design, networking, performance, testing and delivery, in teams of different sizes and, for the last few years, remotely.

On the backend I work with Python and FastAPI on PostgreSQL/PostGIS, organised with Clean Architecture and an OpenAPI contract that the clients are generated from. I use Docker to run databases and to set up stub and mock servers (C#, Python and more) so teams can develop and test against realistic APIs.

On the AI side I work with agents and prompt engineering: phased specs and prompts that drive coding agents, Claude Code, the Claude API, MCP and agent skills. On device I use Speech for offline subtitles. I'm also a certified Scrum Master.
